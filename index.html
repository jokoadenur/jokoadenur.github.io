    Selamat datang di Merkurius

    numspellRRilis di CRAN

    Ini adalah package R pertama saya yang lolos CRAN. Fungsi package ini mendeteksi persistensi numerik (spell) dan pola kekakuan pada data runtun waktu (time series). Package ini juga bisa diterapkan pada data vektor dan frame dan disertai interpretasi berbahasa Indonesia atau Inggris.

    install.packages("numspellR")
library(numspellR)

    senseRRilis di CRAN

    Ini adalah package R kedua saya yang lolos CRAN. Fungsi package ini bermanfaat untuk menilai seberapa layak sebuah indikator proksi menggantikan variabel yang sebenarnya ingin diukur. Misalnya, indeks cahaya malam dari satelit dipakai sebagai pengganti PDB ketika data resmi belum tersedia.

    install.packages("senseR")

    sarimasnap

    Ini adalah package yang saya buat untuk melakukan pemodelan data runtun waktu dengan algoritma Machine Learning terintegrasi sistem grid. Jadi, pengguna akan memperoleh 10 kandidat model runtun waktu, baik musiman atau bukan (seasonal, non-seasonal) berikut dengan ukuran-ukuran akurasinya sebagai bahan pemilihan model terbaik.

    devtools::install_github("jokoadenur/sarimasnap")
segmonr(data)
